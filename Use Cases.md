

| UC\# | Use Case | Description |
| ----- | ----- | ----- |
| **General** |  |  |
| UC-01 | Launch App | User opens the app and sees the home screen with the glasses logo and app name |
| UC-02 | Select a Procedure | User chooses from Insert, Maintenance, or Remove on the Procedures page |
| UC-03 | Connect to XREAL Glasses | App pairs with the XREAL glasses to push the AR overlay/checklist to the HUD |
| UC-04 | Use Voice Input for Navigation | User navigates between pages (Home, Procedures, Settings) using voice commands |
| UC-05 | Receive Audio Prompt | App reads the current step aloud so the user can stay hands-free |
| UC-06 | Talk to AI Assistant | User speaks naturally to the AI assistant for clarifications, warnings, or suggestions |
| UC-07 | Receive AI Safety Alert | AI flags a risk or reminds the user of a missed/important step |
| UC-08 | Display AR Overlay on Glasses | Checklist steps and visual cues are shown on the XREAL glasses display |
| UC-09 | Use App Offline | App functions without WiFi so it works in any clinical environment |
| UC-10 | Open Settings | User accesses Appearance, Terms of Service, and Privacy Policy from Settings |
| UC-11 | View Procedure Log | User accesses a log from the homepage that shows everything the AI noticed during a completed procedure (alerts, warnings, missed steps, timestamps) |
| UC-12 | Exit App | User closes the app from the home screen |
| **Insert** |  |  |
| UC-13 | Start Insertion Procedure | User selects Insert and the step-by-step insertion checklist begins |
| UC-14 | Verify Sterile Field Setup | App prompts user to confirm sterile field is properly set up |
| UC-15 | Hand Hygiene Reminder | App reminds user to perform hand hygiene before proceeding |
| UC-16 | Follow Insertion Steps | App walks user through each insertion step (site prep, gloving, draping, catheter placement) |
| UC-17 | Advance to Next Step | User moves to the next checklist step via voice command or tap |
| UC-18 | Confirm Line Inserted | User confirms insertion is complete; app moves to verification phase |
| UC-19 | Verify Dressing Applied | App prompts user to confirm proper dressing is applied |
| UC-20 | Complete Insertion Procedure | All steps finished; app confirms completion and saves AI log |
| **Maintenance** |  |  |
| UC-21 | Start Maintenance Procedure | User selects Maintenance and the step-by-step maintenance checklist begins |
| UC-22 | Check Dressing Condition | App prompts user to inspect and assess the current dressing |
| UC-23 | Follow Maintenance Steps | App walks user through maintenance steps (hand hygiene, dressing change, line flush, site inspection) |
| UC-24 | Advance to Next Step | User moves to the next checklist step via voice command or tap |
| UC-25 | Complete Maintenance Procedure | All steps finished; app confirms completion and saves AI log |
| **Remove** |  |  |
| UC-26 | Start Removal Procedure | User selects Remove and the step-by-step removal checklist begins |
| UC-27 | Follow Removal Steps | App walks user through removal steps (hand hygiene, clamp line, remove catheter, apply pressure, dress site) |
| UC-28 | Advance to Next Step | User moves to the next checklist step via voice command or tap |
| UC-29 | Confirm Line Removed | User confirms the catheter has been successfully removed |
| UC-30 | Complete Removal Procedure | All steps finished; app confirms completion and saves AI log |
