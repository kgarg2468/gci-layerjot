# CDC CLABSI Prevention Summary

Source URLs:
- https://www.cdc.gov/clabsi/index.html
- https://www.cdc.gov/healthcare-associated-infections/media/pdfs/checklist-for-CLABSI-P.pdf
- https://www.cdc.gov/infection-control/hcp/intravascular-catheter-related-infections/summary-recommendations.html

Status: Team-curated protocol summary for the AR Health demo. Requires clinical review before institutional use.

Core guidance for the assistant:

1. CLABSIs are preventable infections that occur when organisms enter the bloodstream through a central line. The assistant must frame guidance as procedural support and never as diagnosis.
2. For central line insertion, remind clinicians to use maximal sterile barrier precautions: cap, mask, sterile gown, sterile gloves, and full-body sterile drape.
3. Hand hygiene is required before insertion, replacement, access, repair, dressing, or other catheter care activities. If hand hygiene has not been confirmed, raise an advisory warning before the user proceeds.
4. Chlorhexidine with alcohol is the preferred skin antisepsis approach for central venous catheter insertion and dressing changes unless contraindicated by patient-specific policy.
5. Antiseptic must be allowed to dry before catheter placement or dressing application.
6. During maintenance, keep dressings clean, dry, and intact. Scrub hubs/access ports with appropriate antiseptic and friction immediately before use.
7. Assess daily whether the central line is still needed and remove it as soon as it is no longer necessary.
8. AI output must stay advisory. If uncertain, ask the clinician to verify local protocol or consult the attending physician.
